What is BAQ?

BAQ is the utility and access token of the BotRadix ecosystem on Base. It provides an on-chain identity layer for compatible BotRadix access tiers, product capabilities and automation-related ecosystem integrations.

BotRadix publishes this page as the canonical public source for wallets, decentralized exchanges, explorers, market-data platforms, indexers, developers and automated systems that need to resolve the official BAQ contract and metadata.

Token identity & tokenomics

BAQ is an ERC-20 token deployed on Base with 18 decimals and a maximum supply of 5,000,000,000 BAQ. The official contract address is shown above and is the primary identifier that integrations should use.
