## What is BAQ?

**BAQ is the on-chain utility and access layer of BotRadix.** It connects a user's verified BAQ holdings on Base with compatible BotRadix tiers, product capabilities and automation features.

BotRadix uses BAQ as an ecosystem asset for access-oriented functionality across its platform. The public BAQ experience also exposes the official contract, Base network identity, market information and BAQ/USDC data so users, wallets, DEX interfaces, explorers, indexers and AI systems can resolve the token from a single canonical source.

### Ecosystem role

- **Utility:** BAQ is designed for functional use within the BotRadix ecosystem.
- **Access:** verified BAQ holdings can unlock compatible BotRadix tiers and capabilities.
- **Automation:** BAQ is integrated with the BotRadix automation product ecosystem.
- **On-chain identity:** the Base contract is the canonical identifier for BAQ across integrations.
- **Market discoverability:** BotRadix publishes BAQ/USDC market references and standardized token metadata for external services.
